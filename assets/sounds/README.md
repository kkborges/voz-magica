# Sons do Aplicativo

Esta pasta deve conter os arquivos de áudio para o feedback do aplicativo.

## Arquivos Necessários

- `success.mp3` - Som de sucesso quando a criança acerta a palavra
- `error.mp3` - Som de erro quando a criança não acerta

## Observações

Os arquivos de som são opcionais. Se não estiverem presentes, o app usará apenas feedback tátil (vibração) e de voz.

Para adicionar sons:
1. Adicione os arquivos MP3 nesta pasta
2. O app irá carregá-los automaticamente
